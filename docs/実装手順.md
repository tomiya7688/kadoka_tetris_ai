# 実装手順

既存の開発予定.mdを具体化した順序。優先度の指定があればそちらを優先する。
この文書は工程案であり、以下の機能はすべて未実装。

| 順番 | 作業 | 完了条件 |
| --- | --- | --- |
| 1 | 盤面、ミノ定義、7-bag | 7個単位の一意性、seed再現性、衝突をGUIなしで検証 |
| 2 | コマンド、回転、落下、固定、消去、HOLD | 回転表・敗北条件を仕様化し、操作列の再現テストが通る |
| 3 | 固定tick進行と外部コマンド入出力 | 不正入力の拒否と、両陣営への独立した操作を検証 |
| 4 | 最小GUIと人間操作 | 状態表示と手動操作を確認し、コアのGUI非依存を維持 |
| 5 | 到達可能手の探索と評価関数AI | 合法な操作だけで単独プレイでき、固定seedで評価可能 |
| 6 | 対戦、おじゃま、攻撃分析 | 相殺・同時攻撃・敗北のテスト、人間対CPU・AI対AIの確認 |
| 7 | モンテカルロ探索 | ツモ制約を守り、基準AIと同一条件で比較 |
| 8 | 機械学習AI | 観測・行動契約と学習/評価データの分離を検証 |

初回実装前に、GitリポジトリとGitHub公開先を設定・確認する。
詳細設計は対象工程に着手したときに docs/機能名/機能説明書.md へ追加する。
