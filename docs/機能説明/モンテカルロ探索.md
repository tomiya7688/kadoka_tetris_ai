# モンテカルロ探索（可視NEXT版）

`MonteCarloPlanner` は合法な現在配置候補ごとに、観測済みNEXTの範囲で複数のロールアウトを行い、平均報酬で候補を比較する。ロールアウト中の配置候補は評価上位からseed付き乱択で選ぶ。

設定はロールアウト数（1〜10000）、候補幅、可視未来数、seed、割引率。seedと設定が同じなら同じ観測に対し同じ選択を返す。

この版は可視NEXTより先を探索しない。バッグ状態、隠れた将来ツモ、内部乱数状態にはアクセスしない。配置遷移は既存の可視placement plannerを探索補助として使い、C++ core/runtimeのcanonical stateを書き換えない。
