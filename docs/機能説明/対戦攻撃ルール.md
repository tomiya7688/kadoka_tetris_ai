# 対戦攻撃ルール

本プロジェクトの対戦攻撃はTETR.IO標準対戦ルール準拠を目標とする。
詳細な基準・現行実装との差分・実装順序は [TETR.IO準拠ルール](TETRIO準拠ルール.md) を参照する。

## 現在の実装について

`attack_for_clear` は暫定実装であり、Single/Double/Triple/Quadの基礎attackの一部だけを表現している。
現在の以下の処理はTETR.IO完全準拠ではない。

- comboを単純加算する処理
- `back_to_back: bool`だけで扱うB2B
- Spin/Miniを持たないattack計算
- All Clearを持たないattack計算
- incoming/outgoingを整数だけで相殺するcancel

今後はClearResult、Multiplier combo、B2B Charging/Surge、garbage packet queueを導入し、TETR.IO rulesetとして分離する。
